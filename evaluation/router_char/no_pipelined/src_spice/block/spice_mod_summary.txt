Arb measurement correction — 18 September 2026
---------------------------------------------
Current Arb_perf.txt uses a new single-source characterization phase for
header/payload latency and energy. The DUT netlist/sizing did not change.
Historical Arb values in sizing archives used concurrent traffic: header
response includes contention and overlapping supply integrals are not energy
of individual source flits. The current report retains concurrent response
separately and integrates the concurrent episode once. This correction is a
measurement change, not a new sizing gain. Other block sizing results below
are unchanged. See tb/block/results/Arb/Arb_perf.txt and the archive
/home/cad/archives/analog_sim/20260918_arb_measurement/README.md.
